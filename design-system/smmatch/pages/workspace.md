# Workspace routes — SMMatch

Applies to catalog, specialist profiles, task creation, AI tools, customer and specialist dashboards, and admin pages served from the static application shell.

## Purpose

Carry the same dark creator-product shell from the public landing into work-oriented screens without turning the workspace into a marketing page.

## Rules

- Use graphite surfaces (`#10142A`) over the `#060816` canvas. Light mode is derived from the same violet/cyan pair.
- Keep the product header simple: the same text navigation on every public route, an understated secondary action, one violet primary action, and a theme control.
- Use Sora for page titles and key values. Manrope remains the workhorse for controls, tables, filters, and body copy.
- Cards use a 16px radius, 1px low-contrast border, and a quiet shadow only on hover or elevated dialogs.
- Filters, tags, tabs, and sidebar navigation are compact dark chips; active state is violet, with cyan reserved for focus and directional feedback.
- Tables, forms, chats, status states, and dashboards must inherit the same tokens. Gradients are limited to the brand CTA and key visual emphasis.
- On mobile, navigation moves to the full-screen menu; the theme control lives in that menu to preserve header space.
