# Workspace routes — SMMatch

Applies to catalog, specialist profiles, task creation, AI tools, customer and specialist dashboards, and admin pages served from the static application shell.

## Purpose

Carry the warm editorial confidence of the public landing into work-oriented screens without turning the workspace into a marketing page.

## Rules

- Use paper surfaces (`#FFFDF9`) over a warm canvas (`#F4F0E9`); dark mode maps them to graphite (`#211E1A` / `#171513`).
- Keep the product header simple: text navigation, an understated secondary action, one dark primary action, and a theme control.
- Use Calistoga only for page titles and key values. Inter remains the workhorse for controls, tables, filters, and body copy.
- Cards use an 18px radius, 1px low-contrast border, and a quiet shadow only on hover or elevated dialogs.
- Filters, tags, tabs, and sidebar navigation are compact paper chips; active state is warm gold, never neon.
- Tables, forms, chats, status states, and dashboards must inherit the same tokens. No purple/blue gradients or glass panels.
- On mobile, navigation moves to the full-screen menu; the theme control lives in that menu to preserve header space.
